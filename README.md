# 🚗 Cherax Vehicle Copy/Paste

A Gta 5 Cherax tool that copies the appearance of your current vehicle "Base.json" and applies it to every other vehicle.
It also organizes results into vehicle class folders(like Muscle, SUV, Super, etc...).

---

## 📁 Required Files

These must be in the same folder as the ".exe":

- "VehicleList.ini" → a list of all vehicle models and hashes
- "categorized_vehicle_list.txt" → tells the tool which vehicle belongs to which class

---

## 📦 How to Use

1. **Download this repository**
2. Put "CheraxCopyPaste.exe", "VehicleList.ini", and "categorized_vehicle_list.txt" into the same folder
3. Run "CheraxCopyPaste.exe"
4. Click to load your "Base.json" (vhicle saved as "Base" via Cherax that you want to copy to other vehicles)
5. Click "▶ APPLY FROM BASE'
6. A new folder like "Applied from Base", "Applied from Base(2)" will appear
7. Inside, your files will be neatly organized by vehicle class

---

## ✅ Features

- Copy the look of your GTA Online vehicle
- Generate JSON presets for **every vehicle** in GTA Online
- Organize applied copies to vehicle class
- No internet or dependencies needed

---

## ✅ Compatible With

- **Cherax Mod Menu**
- GTA V (Online or Story Mode)
